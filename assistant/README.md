# Personal Assistant — Memory

These files are the assistant's brain. Scheduled tasks read them every run and update them when you report changes (e.g. "we're out of rice", "I'm flying to Delhi on the 15th").

| File | Purpose |
|---|---|
| `profile.md` | Who you are: home city/timezone, preferences |
| `important-dates.md` | Birthdays, anniversaries, and how to reach each person |
| `travel.md` | Current/upcoming trips (drives dual-timezone + weather in briefings) |
| `pantry.md` | What's in stock, running low, or out |
| `meal-schedule.md` | Weekly meal plan + ingredient needs |
| `shopping-list.md` | Auto-generated from pantry + meal plan |
| `work.md` | Repos, Linear team, and standing work preferences |

Edit any file by hand anytime, or just tell Claude in chat — it will update the right file.
